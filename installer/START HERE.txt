CHAINED BEASTS - FRIEND INSTALLER

1. Extract this ENTIRE ZIP to a folder (for example, on your Desktop).
2. Close Chained Beasts.
3. Double-click INSTALL.bat. It searches Steam libraries and local drives and
   automatically uses a single compatible game installation.
   Only if discovery is inconclusive will you need to select the game folder.
   If Windows asks for administrator permission, approve with your own account.
4. Wait for the green INSTALLED message, then start the game normally in Steam.
   Choose Solo. First startup can take several minutes; let it finish.

INCLUDED
- BepInEx 6.0.0-be.791+b782da4, Windows x64 Unity IL2CPP, unmodified official ZIP
- ChainedBeasts.ModFoundation 0.8.3 (required framework)
- Terms & Contusions 0.8.3 (custom skills, equipment, potion effects and surgeries)
- Battle Numbers 0.1.1 (floating damage numbers)

Installation and BepInEx's first-launch setup do not need a download. The exact
Unity 6000.3.21 reference ZIP is included and configured as a local file with no
HTTP fallback. First game startup still generates bindings on your computer.
This does not change the game's own Steam/network behavior.
You do not need PowerShell 7 or a .NET SDK. Windows PowerShell is already included.
The installer requests UAC permission automatically if the Steam folder needs it.
No permanent execution-policy or security settings are changed.

Only the inspected Steam Windows x64 game build 1.0.1 is accepted. The installer
stops on a different game build or conflicting loader rather than mixing versions.
It preserves your settings except the Unity-library source in BepInEx.cfg, which
is pointed to the included offline ZIP. It removes backed-up duplicate copies
of the three bundled plugin assemblies. Don't start the game during installation.

Backups: %LOCALAPPDATA%\ChainedBeastsModInstaller\Backups
Each backup includes plugins, config, your complete game user-data folder (if it
exists), replaced files, hashes, installation.json and ROLLBACK.txt. Keep it.
Saves are copied only; the installer never edits them. No personal data is bundled.

Custom content descriptions begin TC:. Offers are random, not guaranteed. The F1
developer panel is optional; cheats start off. Content is unbalanced examples.
Solo only. Some boss hits don't show numbers. Surgery rerolls can keep the same
offers. Do not remove custom content from an active saved run that owns it.

Settings (generated on first launch, close the game before editing):
  BepInEx\config\local.chainedbeasts.modfoundation.cfg
  BepInEx\config\local.chainedbeasts.termsandcontusions.cfg
  BepInEx\config\local.chainedbeasts.battlenumbers.cfg

Report problems with Player.log from:
  %USERPROFILE%\AppData\LocalLow\Featherweight Games\ChainedBeasts
Also include BepInEx\LogOutput.log and what happened. Copy before relaunching.

Sources, licenses and notices are in licenses and SOURCES.txt. This is an unofficial
mod bundle; the game itself and generated game bindings are not included.

UNINSTALL
1. Finish or abandon a run that owns custom content while the mod is installed.
   Removing its content can prevent that run from loading.
2. Close Chained Beasts and double-click UNINSTALL.bat from this extracted folder.
3. Check the displayed game folder, then type UNINSTALL to confirm.

It uses your installer backup records to undo the bundle, including repeated
installs. Replaced/removed previous plugin files are restored, so mods you already
had before the bundle may remain. Your saves, settings, generated interop and logs
are preserved; a current backup is made before removal. No save is restored.

A new loader is removed only if the bundle introduced it and no other plugins or
patchers need it. A pre-existing or modified loader is kept. This avoids disabling
other mods. Generated folders/files can remain after uninstall; these are harmless
without the loader bootstrap. Keep the backups under the same Windows account.
The offline reference ZIP and loader config remain together after uninstall.
Changed mod DLLs or missing/corrupt backup records stop automatic uninstall.
