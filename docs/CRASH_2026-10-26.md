## Preserved evidence

- Full pre-fix source/build/configuration/current user-data/plugin checkpoint: `backups/expansion-stage7-crash-20261026-071546-500`. Raw BepInEx and Player logs were copied into its ignored `raw-logs` directory before any fix. These private files are not distributed or versioned.
- Both 0.8.0 plugins reached chainloader startup. The BepInEx log was 21,861,321 bytes, with **77,673** identical Projectile.OnDespawn trampoline exceptions starting before gameplay. This is a new mod failure, distinct from the existing Class::Init signature warning and native look-rotation/mesh warnings.
- Native disassembly/ISIL of the installed game's Projectile.OnDespawn is a single ret. An offline GameAssembly method-table audit confirms its RVA `0x6005a0` is shared by **433 managed method slots**, while OnDestroy RVA `0x764710` occurs once and has a substantial body. The method was detoured by NativeThrowing despite being a shared native no-op. Its managed wrapper alone had passed earlier metadata checks; those checks did not verify native-body safety.
- Eleven new skills each failed factory registration with `Native skill visual source missing`; Bulk Up's separate existing fallback was unaffected. These are confirmed startup failures independent of whether the native hard crash has another contributor.
- No native crash dump or matching WER fault stack was located in the inspected crash-report locations. The unsafe detour is a likely contributor; this investigation does not establish a sole native crash cause.
